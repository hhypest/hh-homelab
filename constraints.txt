# Точные версии всего, что ставится в проверках, — включая транзитивные
# зависимости, которых в requirements-dev.txt нет.
#
# Зачем отдельный файл. В requirements-dev.txt стоят нижние границы (>=):
# они говорят, что нужно проекту. Верхних границ там нет, поэтому CI ставил
# то, что вышло сегодня, и один и тот же коммит мог быть зелёным вчера
# и красным сегодня — без единой правки в репозитории. Отладить такое
# нельзя: локально стоит другой набор.
#
# Файл ограничений эту дыру закрывает, не трогая requirements-dev.txt:
# pip install -r requirements-dev.txt -c constraints.txt
#
# Ограничение — это не установка. Строка отсюда действует, только если пакет
# и так ставится: на Python 3.13 часть строк ниже просто не понадобится,
# и это нормально.
#
# Обновляется не руками: раз в месяц Dependabot (группа «проверки»)
# приносит PR с новыми версиями, проверки на нём прогоняются, и видно,
# что именно сломалось. Пересобрать набор целиком:
#
#     python3 -m venv /tmp/c && /tmp/c/bin/pip install -r requirements-dev.txt
#     /tmp/c/bin/pip freeze
